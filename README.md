# Calculadora Elétrica RD — PWA 1.0

Aplicativo web progressivo para cálculos preliminares de corrente elétrica, ampacidade de condutores e queda de tensão.

## Recursos

- Instalação no iPhone, iPad, Android e Windows.
- Funcionamento offline após o primeiro carregamento.
- Interface responsiva e armazenamento local dos últimos parâmetros.
- Memória de cálculo com cópia, impressão e exportação em PDF pelo navegador.

## Privacidade

Os cálculos e parâmetros permanecem no dispositivo. O aplicativo não possui servidor, banco de dados, conta de usuário, telemetria ou bibliotecas externas.

## Limitações

Ferramenta de dimensionamento preliminar. Os resultados devem ser conferidos por profissional habilitado e não substituem a verificação integral da ABNT NBR 5410 nem os dados dos fabricantes.

Consulte `LEIA-ME.txt` para instruções de instalação, funcionamento offline e detalhes técnicos.
